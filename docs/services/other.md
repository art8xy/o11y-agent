## Other Services
The following document describes other services available in the deployment.

### OpenTelemetry Demo
OpenTelemetry Demo is a sample application designed to simulate a microservice application environment.
- **Web Store:** https://otel-demo.o11y.local
- **Load Generator:** https://otel-demo.o11y.local/loadgen
- **Feature Flags:** https://otel-demo.o11y.local/feature
- **Official Docs:** https://opentelemetry.io/docs/demo

### CloudnativePG
CloudnativePG is used to manage PostgreSQL databases within the cluster.
- **Official Website:** https://cloudnative-pg.io

### Traefik
Traefik is used as the gateway for routing traffic to services in the cluster.
- **Official Website:** https://traefik.io

### Metallb
Metallb provides IP address for the gateway.
- **Official Website:** https://metallb.io
